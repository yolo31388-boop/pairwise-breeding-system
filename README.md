# pairwise-breeding-system

宠物繁殖与基因系统（纯标准库）：

- 显性/隐性/共显性基因，表现型由基因型决定
- 变异率基础 1%，可由道具、父母品质、繁殖次数提升
- 性别概率权重，可通过道具（如 `female_potion`）影响
- 技能按稀有度 × 父母技能等级加权继承
- 父母双方均有繁殖冷却，并记录各自繁殖次数
- 成长率在父母均值基础上 ±10% 波动
- 后代出生为幼年期，需喂养（`feed`）或时间（`tick`）才能成年
- 近亲繁殖按亲缘系数产生缺陷，系统记录族谱（`pedigree`/`is_related`）
